## 🤝 What I Did vs. What the Agent Did

**I drove intent, structure, and quality gates.**
I wrote the creative brief, defined the information architecture, chose the color palette direction, approved or rejected every generated component, and caught edge cases the agent couldn't anticipate (viewport quirks, accessibility gaps, copy that sounded robotic).

**The agent handled execution velocity.**
It scaffolded the full file structure, generated pixel-level CSS (gradients, glassmorphism, animations), wired up interactivity, wrote SEO meta tags, and iterated on designs in seconds — work that would have taken me days alone.

In short: I was the product manager and the agent was a very fast, occasionally overconfident senior engineer.

## 🤦 The Dumbest Thing the Agent Tried to Ship

> *A hero section with a fully animated, GPU-melting **CSS particle system** — 2,000 `<div>` elements injected into the DOM via JavaScript on page load — for a **marketing landing page** whose #1 job was fast LCP.*

It was visually stunning in a localhost tab.
It scored **11 on Lighthouse performance** on a mid-range Android device.
I killed it, replaced it with a single `@keyframes` CSS gradient animation, and LCP went from 4.8 s → 1.2 s.

Lesson: the agent optimizes for *wow* before it optimizes for *works*.

---

## 🔁 What I'd Do Differently Next Time

**Lead with constraints, not just a prompt.**
Next time I'll front-load the agent with hard rules upfront — max DOM node count, Lighthouse performance budget, accessibility checklist, and target device profile — so it can't ship a beautiful disaster and call it done.

Agents are junior devs with infinite energy and zero shame about tech debt. Your job is to be the senior who sets the guardrails *before* the sprint, not after the code review.
